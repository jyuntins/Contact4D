# Contact4D: A Video Dataset for Whole-Body Human Motion and Finger Contact in Dexterous Operations

**[Project Page](https://jyuntins.github.io/Contact4D/) · [Paper](https://ieeexplore.ieee.org/abstract/document/11533240) · [Dataset](https://huggingface.co/datasets/Jyun-Ting/Contact4D/tree/main) · [Toolkit](https://github.com/jyuntins/Contact4D_Toolkit)**

Jyun-Ting Song, JungEun Kim, Jinkun Cao, Yu Lei, Takuma Yagi, Kris Kitani — 3DV 2026

Contact4D is a multi-view video dataset of people assembling furniture, with ground-truth per-fingertip contact labels, 2D/3D body and hand keypoints, fitted SMPL / SMPL-X / MANO parameters, and calibrated exocentric + Project Aria egocentric views. It covers 34 capture sessions, 448 sequences, 8 scenes, 6 furniture types, and 2.68M images.

This repository hosts the source of the [Contact4D project page](https://jyuntins.github.io/Contact4D/). To download the data, see [Hugging Face](https://huggingface.co/datasets/Jyun-Ting/Contact4D/tree/main); to load and visualize it, see the [Contact4D Toolkit](https://github.com/jyuntins/Contact4D_Toolkit).
